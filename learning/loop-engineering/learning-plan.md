# 学习计划：Loop Engineering（Agent 循环工程）

> 用户场景：面试 / 会议前补课——目标是**对答如流**，不是独立实现。阶梯的里程碑和自测题据此设计：第 3-4 级不考"能不能写代码"，考"能不能在对话里把框架用在新场景上、扛住追问"。

## 第 6 步 · 学习阶梯

### Lv.1 完全初学者

1. **应理解**：agentic loop 是什么；tool_use → 执行 → tool_result 的三段式；四层演进阶梯（prompt→context→harness→loop）；五个必备部件
2. **"掌握"的样子**：能不看笔记复述一句话定义和四层阶梯
3. **重点关注**：循环 vs 自动化的分水岭——**目标验证步**；模型自己不执行任何东西，只请求
4. **进阶里程碑**：能用 2 分钟给一个外行讲清楚"agent loop 和只调一次 API 有什么不同"，不卡壳
5. **动手练习**：挑一个具体例子（比如"agent 修一个代码 bug"），把五个部件（trigger/goal/tools/verification/stopping rule）逐个对应说出来——不用写代码，说出来就行
6. **常见错误**：把"agent"和"聊天机器人"混为一谈；以为循环需要好几个不同模型协作；忘记模型不能自己执行工具
7. **自测题**：为什么模型自己不执行任何东西？谁来执行？

### Lv.2 基本理解

1. **应理解**：`stop_reason` 的几种状态；compaction（压缩）vs context editing（编辑）的区别；prompt caching 的前缀敏感性；护栏的具体类型（迭代上限/成本预算/无进展检测/熔断/人工介入点）
2. **"掌握"的样子**：能不混淆地讲清楚"上下文快满了会发生什么、有哪几种应对手段"
3. **重点关注**：**compaction 和 context editing 是两件不同的事**——一个是总结，一个是剪枝，这是最容易被混着讲错的一对概念
4. **进阶里程碑**：给定一个失败场景描述，能指出"哪种护栏本可以防住它"
5. **动手练习**：拿资源 4（Cyera 报告）里 PocketOS 和 Replit 两个案例，分别说出"如果加了哪种护栏，这次事故本可以避免"
6. **常见错误**：把 compaction 和 context editing 当成同一件事；以为"扩大上下文窗口"就能解决 context rot
7. **自测题**：compaction 和 context editing 有什么区别？

### Lv.3 实际使用者（对你：能把框架套用到新场景，不是能写代码）

1. **应理解**：五视角各自的立场和证据；目前领域最大的悬而未决问题（护栏是否真提升成功率）
2. **"掌握"的样子**：拿到一个没见过的场景（比如"公司想用 agent 自动分诊客服工单"），能当场口头拆出 trigger/goal/verification/stopping rule
3. **重点关注**：**可验证目标设计**——这是整个领域的成败关键，也是面试里最容易被深挖的点
4. **进阶里程碑**：任何一个模糊的任务描述，都能不看提示改写成"触发器+可验证目标"的一句话
5. **动手练习**：挑 3 个假设场景（工单分诊 / PR 审阅机器人 / 报销单审核），每个场景在 60 秒内口头说出它的 trigger/goal/stopping rule
6. **常见错误**：写出机器不可判定的目标（"让它更好"）；忘了设停止规则；把"agent 能做 X"和"agent 该无人值守地做 X"混为一谈
7. **自测题**：给一个模糊需求"帮我把收件箱清干净"，你会怎么把它改写成一个可验证目标？

### Lv.4 问题解决者（扛住追问）

1. **应理解**：矛盾图谱里的核心分歧（护栏是解法还是止损）；Rice 定理/Goodhart 那条结论的正确措辞（是"尚待核实的强断言"，不是"已证明"）；具体事故案例；经济激励批判
2. **"掌握"的样子**：被问"这是不是纯炒作"时，能给出结构化、不慌乱的回答
3. **重点关注**：**区分"loop engineering 这个词"（炒作、短命）和"它指向的真实问题"（持续存在）**——这是应对刁钻追问的最高杠杆点
4. **进阶里程碑**：面对"所以这就是纯炒作吧"这句话，能用"这个词才一个多月大、但有 2001 年 MAPE-K 先例、有真实生产事故、但也有厂商按 token 计费的利益驱动"这个结构回答，不卡壳
5. **动手练习**：模拟问答——把这三个刁钻问题的回答写下来或说出来：「这不就是加了个 while 循环加重试吗？」「我凭什么信厂商博客说的这些最佳实践？」「这里真正没解决的问题到底是什么？」
6. **常见错误**：把"加护栏能解决循环问题"说成行业共识（这是有争议的，不是共识）；把 Rice 定理那条结论讲成"已证明"而不是"尚待核实"
7. **自测题**：如果面试官说"这不就是加了个 while 循环加重试吗，有什么好谈的"，你怎么接？

### Lv.5 自信的实践者

1. **应理解**：以上全部，整合成一个连贯的叙事；能主动带出前沿问题和治理盲区，展示超出被问范围的深度
2. **"掌握"的样子**：能主导 5-10 分钟的相关对话，不需要对方一直提问带节奏
3. **重点关注**：**知道什么时候该收着说**——深度是通过恰当的保留表现出来的（比如不过度断言 Rice 定理），不是靠堆更多事实
4. **进阶里程碑**：能不看速查表、用自然对话的语气（不是背列表）把速查表内容讲一遍
5. **动手练习**：掐表做一次 5 分钟的模拟独白——"跟我讲讲你对 loop engineering 的了解"，不看笔记，录下来或说给自己听
6. **常见错误**：把对话变成信息倾倒，而不是交流；忘了先问对方"你更想听哪个角度"再展开，而是自顾自讲完全部
7. **自测题**：做完第 6 项的独白练习后自我复盘——有没有举一个真实案例？有没有对不确定的结论做适当保留？有没有主动带出前沿问题？
